# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- **Principal (P):** the initial amount of money
- **Rate (R):** the annual rate of interest, in percent
- **Time (T):** the time period, in years

## Usage

1. Clone the repository:
```bash
   git clone https://github.com/aakashdarda2907/simple-interest-calculator.git
   cd simple-interest-calculator
```
2. Make the script executable:
```bash
   chmod +x simple-interest.sh
```
3. Run it:
```bash
   ./simple-interest.sh
```
4. Enter the principal, rate of interest, and time period when prompted.

## Example

```
Enter the principal amount: 1000
Enter the rate of interest: 5
Enter the time period (in years): 2
Simple Interest = 100
```
